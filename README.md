# TTU STORE - نسخة كاملة (تصميمك + حسابات حقيقية)

مشروع Flask كامل، بنفس شكل موقعك بالضبط (البانر، الفئات، البحث، تبديل اللغة)
لكن مع حسابات حقيقية، سلة تُحفظ كطلب في حسابك، ولوحة تحكم لإدارة كل حاجة.

## المميزات
- نفس تصميم موقعك (بنفسجي نيون، Cairo font، بانر متحرك، فئات دائرية، بحث فوري)
- كل منتجاتك الحالية (26 منتج) موجودة جاهزة من أول تشغيل
- تسجيل دخول/حساب للعميل
- سلة تجميع منتجات (مش طلب منفصل لكل منتج)
- "إتمام الطلب" من السلة يتطلب تسجيل دخول، ويحفظ الطلب في حساب العميل
- رفع إثبات الدفع بعد إتمام الطلب
- صفحة "حسابي" فيها سجل كامل للطلبات وحالتها (معلق/مكتمل/فشل)
- لوحة تحكم لك: إدارة المنتجات (إضافة/تعديل/حذف) وإدارة الطلبات

## خطوات التشغيل (ويندوز)

### 1. فك الضغط
فك ضغط الملف، هيطلعلك مجلد `store_v2`.

### 2. فتح الطرفية جوا المجلد
افتح مجلد `store_v2`، امسح اللي في شريط العنوان فوق واكتب `cmd` واضغط Enter.

### 3. تثبيت المكتبات
```
pip install -r requirements.txt
```

### 4. تشغيل السيرفر
```
python app.py
```
أول مرة تشغّل، هيتعمل ملف قاعدة بيانات `store.db` وهتتحط فيه كل منتجاتك الـ26 تلقائياً.

افتح المتصفح على:
```
http://127.0.0.1:5000
```

### 5. إنشاء حساب أدمن (أنت)
افتح نافذة `cmd` تانية (بنفس طريقة خطوة 2) والسيرفر لسه شغال في الأولى، واكتب:
```
flask create-admin
```
هيطلب اسمك وإيميلك وكلمة مرور. بعدها سجّل دخول من:
```
http://127.0.0.1:5000/login
```
ولوحة التحكم من:
```
http://127.0.0.1:5000/admin
```

## طريقة عمل المتجر الآن
1. العميل يتصفح المنتجات ويضيفهم للسلة (زرار 🛒)
2. من السلة يضغط "إتمام الطلب" — لو مش مسجل دخول هيتوجه لصفحة الدخول
3. بعد الدخول، الطلب يتحفظ وتظهر صفحة فيها رقم المحفظة لتحويل المبلغ
4. العميل يرفع صورة إثبات الدفع
5. الطلب يظهر عندك في لوحة التحكم (admin/orders) بحالة "معلق"
6. تتأكد من الدفع، وتغيّر الحالة لـ "مكتمل" وترسل المنتج يدوياً على واتساب/إيميل العميل
7. العميل يشوف تحديث الحالة في صفحة "حسابي"

## إضافة/تعديل منتج
كل حاجة من لوحة التحكم `admin/products` — مفيش حاجة تتعدل من الكود بعد كده.

## ملاحظات قبل النشر الفعلي
- غيّر `SECRET_KEY` في app.py
- لا تشغّل `debug=True` على سيرفر حقيقي
- رقم المحفظة الإلكترونية مكتوب حالياً في `templates/order_payment.html` — غيّره لرقمك
